# Live Fyers ML Trading System

## Objective

This project implements a live market-data processing and machine-learning prediction system using the Fyers API/WebSocket.

The system receives real-time market data, processes the incoming ticks, calculates features, generates ML predictions and confidence scores, records signals, and evaluates prediction performance against subsequent actual market movement.

## ML Model

Random Forest Classifier is used for predicting future price direction.

The model uses features including:

- Short-term return
- Multi-period return
- Moving averages
- Volatility
- Moving-average difference
- Price position

The model's `predict_proba()` output is used to calculate prediction confidence.

## Live Data

The application receives live market data using the Fyers WebSocket.

The live data is stored in:

3_data_and_model/day1/live_data.csv

## Predictions

ML predictions are stored in:

3_data_and_model/day1/live_predictions.csv

Each prediction contains:

- Timestamp
- Symbol
- LTP
- Signal
- Confidence

## Evaluation

Predictions are evaluated against subsequent actual market prices.

The evaluation calculates:

- Total predictions
- Correct predictions
- Incorrect predictions
- Success rate
- Average confidence

## Running the Project

Install dependencies:

pip install -r requirements.txt

Create `.env`:

FYERS_APP_ID=YOUR_APP_ID
FYERS_ACCESS_TOKEN=YOUR_ACCESS_TOKEN
SYMBOL=NSE:SBIN-EQ

Run the live backend:

python 1_source_code/run_live.py

Run the dashboard separately:

streamlit run 1_source_code/dashboard.py

## Important

The project requires a valid Fyers API application and access token.

No static or simulated market data is used for the final live demonstration.

Performance results are generated from actual collected market data.
